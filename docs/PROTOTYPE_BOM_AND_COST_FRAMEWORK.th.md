# กรอบ BOM และต้นทุนต้นแบบ PUI89 สำหรับผลิตภัณฑ์ 6 รายการ

**เวอร์ชัน:** 1.0  
**วันที่ทบทวน:** 28 พฤศจิกายน 2026  
**สถานะ:** เอกสารวางแผนเท่านั้น ไม่ได้หมายถึงการอนุมัติซื้อ การเลือกผู้จำหน่าย การกำหนดฮาร์ดแวร์ขั้นสุดท้าย หรือการยืนยันต้นทุนต้นแบบ

เอกสารนี้กำหนดวิธีจัดหมวดฮาร์ดแวร์ วัสดุ ส่วนประกอบ และต้นทุนต้นแบบให้เป็นมาตรฐานเดียวกันสำหรับผลิตภัณฑ์ PUI89 ทั้ง 6 รายการ หากยังไม่ทราบรุ่นหรือราคาให้ระบุ **TBD** ห้ามสร้างชื่อผู้ผลิต หมายเลขชิ้นส่วน ประเทศต้นกำเนิด ผู้จำหน่าย ใบเสนอราคา หรือต้นทุนขึ้นเอง

## 1. หลักเกณฑ์การประเมินต้นทุน

1. กำหนด configuration และ revision ของต้นแบบ รวมถึงจำนวน ก่อนเริ่มประเมินต้นทุน
2. บันทึกผู้ผลิต รุ่น/หมายเลขชิ้นส่วนที่แน่นอน หลักฐานประเทศที่ผลิต/ต้นกำเนิด ผู้จำหน่าย URL วันที่ใบเสนอราคา สกุลเงิน ราคาต่อหน่วย จำนวน ค่าขนส่ง ภาษี และระยะเวลาจัดส่ง
3. แยกราคาใบเสนอราคา ราคาหน้าเว็บสาธารณะ ราคาย้อนหลัง และงบประมาณเผื่อทางวิศวกรรม ห้ามนำเสนอเสมือนเป็นข้อมูลประเภทเดียวกัน
4. ระบุแหล่งที่มาและวันที่ของอัตราแลกเปลี่ยนเมื่อใช้สกุลเงินอื่น
5. แยกค่าผลิตชิ้นงาน ค่าประกอบ/ผสานระบบ อุปกรณ์ทดสอบ วัสดุสิ้นเปลือง ค่าขนส่ง อากร/ภาษี และเงินสำรองออกจากกัน
6. ระบุรายการที่ไม่รวมและสมมติฐาน งบประมาณประมาณการไม่ใช่ใบเสนอราคาจากผู้จำหน่ายหรือการอนุมัติจัดซื้อ
7. ห้ามเลือกหรือซื้อชิ้นส่วนก่อนตรวจสอบความเข้ากันได้ ความปลอดภัย สิทธิ์/ที่มา และได้รับอนุมัติจากผู้ใช้
8. ให้ความสำคัญกับฮาร์ดแวร์และผู้จำหน่ายที่ไม่ใช่แหล่งกำเนิดจากจีนเมื่อเป็นข้อกำหนด โดยต้องมีหลักฐานแหล่งกำเนิด ไม่อนุมานจากประเทศสำนักงานใหญ่ของแบรนด์

## 2. หมวด BOM กลาง

| หมวด | รายการที่ต้องบันทึก |
|---|---|
| โมดูลประมวลผล | SBC/Edge Computer, โมดูล CPU/GPU/NPU, Carrier Board, ระบบระบายความร้อน, Storage |
| ระบบควบคุมฝังตัว | บอร์ด MCU, Motor-control Board, Safety Controller, I/O |
| หน่วยความจำและจัดเก็บ | RAM, Flash, SSD, Removable Storage |
| เซนเซอร์รับรู้ | กล้อง RGB/CMOS, Depth, Thermal, LiDAR, Radar, Microphone, Encoder |
| ตำแหน่งและการเคลื่อนไหว | IMU, GNSS, Wheel Odometry, Magnetometer และอุปกรณ์ช่วยระบุตำแหน่ง |
| การสื่อสาร | Ethernet, Wi-Fi, Bluetooth, Cellular Modem, Antenna |
| ระบบขับเคลื่อน | Motor, Servo, Gearbox, Motor Driver, Brake, Steering หรือ Drive Assembly |
| พลังงาน | Battery Cell/Pack, BMS, Charger, DC-DC, Fuse, Contactor, Wiring |
| โครงสร้างและวัสดุ | Frame, Chassis, Enclosure, ล้อ/ขา, Joint, Fastener, Protective Cover |
| ความปลอดภัยและการป้องกัน | Emergency Stop, Bump/Contact Sensor, Interlock, Thermal Protection, Ingress Protection |
| การผลิตและผสานระบบ | Machining, 3D Printing, Welding, Assembly, Harnessing, Calibration |
| การทดสอบและโลจิสติกส์ | Test Fixture, วัสดุสิ้นเปลือง, ค่าขนส่ง, อากร/ภาษี, บรรจุภัณฑ์ |

**ห้ามนับต้นทุนซ้ำ:** หากบอร์ดหรือโมดูลที่ซื้อมี CPU, GPU, NPU, MCU, Memory, CMOS Sensor, IMU, GNSS Receiver, Motor Driver หรือ Power IC ติดตั้งอยู่แล้ว ให้ลงต้นทุนเป็นบอร์ด/โมดูลสำเร็จรูป ส่วนชิปภายในบันทึกเป็นข้อมูลสเปก ไม่ใช่รายการต้นทุนเพิ่ม เว้นแต่ซื้อแยกจริง

สูตรคำนวณ:
- **ยอดรวมฮาร์ดแวร์** = ผลรวมราคาต่อหน่วยที่ตรวจสอบแล้ว × จำนวน
- **ค่าผลิตและผสานระบบ** = รายการค่าแรง/บริการ/วัสดุที่มีหลักฐาน แยกต่างหาก
- **โลจิสติกส์และภาษี** = ค่าขนส่ง อากร และภาษีที่ระบุแยก
- **เงินสำรอง** = จำนวนเผื่อที่ระบุเหตุผลชัดเจน
- **งบประมาณต้นแบบ** = ผลรวมข้างต้น พร้อมระบุรายการที่ไม่รวม

จนกว่าจะมีใบเสนอราคาและหลักฐาน configuration ต้นทุนต้นแบบของแต่ละผลิตภัณฑ์ให้ระบุ **TBD — ยังไม่มีข้อมูลเพียงพอสำหรับประเมินอย่างรับผิดชอบ**

## 5. เครื่องมือวิศวกรรมที่ใช้ร่วมกัน

บันทึกเครื่องมือที่ใช้ร่วมกันแยกจาก BOM ของแต่ละผลิตภัณฑ์ เพื่อไม่คิดต้นทุนซ้ำ 6 ครั้ง ตัวอย่างเช่น เครื่องมือวัด อุปกรณ์บัดกรี/ซ่อม เครื่องมือย้ำสาย Calibration Target อุปกรณ์ทดสอบ คอมพิวเตอร์ทดสอบ และบอร์ดพัฒนาที่ใช้ซ้ำได้ ให้ระบุเจ้าของ ความพร้อม สภาพ และวิธีจัดสรร เอกสารนี้ไม่ได้อนุมัติให้ซื้อเครื่องมือใด ๆ

## 6. หลักฐานและการควบคุมการเปลี่ยนแปลง

- เก็บ URL ต้นทาง ภาพ/ไฟล์ใบเสนอราคา และวันที่เข้าถึง
- ตรวจสอบประเทศที่ผลิต/ต้นกำเนิดของชิ้นส่วนแต่ละรายการ แค่สัญชาติของแบรนด์ไม่เพียงพอ
- ตรวจสอบข้อจำกัดการส่งออก การรับรองอุปกรณ์วิทยุ กฎขนส่งแบตเตอรี่ ความปลอดภัยทางไฟฟ้า และกฎหมายยานยนต์ก่อนจัดซื้อหรือทดสอบ
- ตรวจสอบสถานะเลิกผลิต การสนับสนุน Firmware และประกาศด้านความปลอดภัย
- ปรับเอกสารภาษาอังกฤษและภาษาไทยควบคู่กัน
- แยกสถานะ เสนอ / ได้ใบเสนอราคา / ซื้อแล้ว / ผสานแล้ว / ทดสอบแล้ว
- ไม่มีการเลือกผู้จำหน่าย และไม่มีการอนุมัติซื้อหรือผูกพันใด ๆ จากกรอบนี้
